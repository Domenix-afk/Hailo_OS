- `omni_engine.py` → `omni_engine_backup.py`
- `main.py` → `main_backup.py`
- `App.jsx` → `App_backup.jsx`
- `index.css` → `index_backup.css`

### Step 2: Activate
Run either:
- `activate_optimizations.bat` (Windows)
- `./activate_optimizations.sh` (Linux/Mac)

### Step 3: Verify
```bash

```

### Step 4: Start
```bash
start.bat both          # Windows
./start.sh both         # Linux/Mac
```

## 🔄 ROLLBACK PROCEDURE

If needed, revert to original versions:

```bash
# Backend
cd backend
copy omni_engine_backup.py omni_engine.py
copy main_backup.py main.py

# Frontend
cd ../frontend/src
copy App_backup.jsx App.jsx
copy index_backup.css index.css

# Restart
cd ../..
start.bat both          # Windows
./start.sh both         # Linux/Mac
```
